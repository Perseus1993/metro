# 立法研究：理论—生产问题映射

研究日期：2026-08-02  
性质：非正式立法材料，不具有法律效力。  
边界：本文不判断代码是否合规，不执行校准、测试或验收，也不指定实现。

## 研究目的

本研究只把文献中反复出现的普遍原则与现有设计暴露出的风险对应起来，用于解释 `LAWS.md` 为什么需要这些法律。当前代码事实只构成立法背景，不构成执法结论。

## 立法研究结论

1. 当前最需要法律约束的是**名称、边界、来源和证据等级**，不是某个具体算法实现。
2. 法律可以要求生产体系在作出特定主张时具备校准或验证证据，但元老院不生产、检查或批准这些证据。
3. 任何关于类、接口、日志格式、测试集合和工程顺序的选择，都不进入法典。
4. 若未来出现新的普遍性问题，应先作为立法研究记录；只有能写成跨实现、跨版本的“必须/不得”规则时，才进入法典。

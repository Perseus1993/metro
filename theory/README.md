# Theory 元老院

本目录是地铁站微观客流仿真的独立理论元老院，只用于：

- 保存可合法获取的论文全文、书目信息与来源；
- 记录逐篇解读、证据强度和适用边界；
- 从学术证据中提炼长期、通用的算法法律；
- 颁布、解释、修订和废止法律。

最高规范见 [元老院宪法](CONSTITUTION.md)，立法程序见 [立法章程](SENATE_CHARTER.md)，现行规则只以 [元老院法典](LAWS.md) 为准。

## 与生产系统的边界

- 生产代码不得导入本目录中的任何文件。
- 运行时配置、模型参数和测试基准不得直接从本目录读取。
- 文献中的公式与参数只有在形成明确的设计决策、数据依据和验证方案后，才可另行进入生产代码。
- 本目录中的法律不等于“已实现”“已校准”“已验证”或“已合规”。
- 本目录不编写代码，不指定实现方案、负责人或工期。
- 本目录不执行校准、测试、执法、合规审查或发布验收。

## 目录

- `INDEX.md`：总入口、核心结论与阅读顺序。
- `CONSTITUTION.md`：元老院的最高规范与权力边界。
- `LAWS.md`：唯一现行算法法典。
- `SENATE_CHARTER.md`：立法程序。
- `papers/`：论文全文；仅保存开放获取版本、作者稿或已获授权的副本。
- `notes/`：逐篇证据卡片，区分原文结论和项目解释。
- `reports/`：非正式立法研究，不具有法律效力。
- `sources/`：书目、检索日期、下载地址、版本和文件校验信息。

## 证据状态

每篇论文使用以下状态之一：

- `full_text_verified`：全文已获取，书目信息和 PDF 内容已核验。
- `metadata_verified`：书目信息已核验，但没有合法可下载全文。
- `candidate`：仅来自清单，尚未完成独立核验。
- `citation_issue`：题名、作者、年份或出处存在疑点，不能作为确定引用。

## 生产隔离检查

每次归档验收应确认构建配置、包发现、运行入口和测试收集都没有依赖 `theory/`。

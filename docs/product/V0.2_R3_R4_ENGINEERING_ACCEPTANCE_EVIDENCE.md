# V0.2 R3/R4 工程验收证据

- 验收日期：2026-07-16
- 范围：V02-DEV-009～013 的工程部分
- 工程结论：**pass**

## 结论

V0.2 最小工程范围已经贯通，可以结束功能开发并转入真实用户验收。R3 的算法注册、严格配对计划和算法证据报告通过；R4 的模板、浏览器黄金路径、实验包导出/导入复跑、失败隔离、全量回归和正式站型 smoke 通过。

V02-DEV-013 整体仍标记为 `conditional`，因为“5 次目标用户任务”和“2 名独立参与者插件接入”不能由自动化代替。本证据不把它们记为通过。

## 实现证据

### V02-DEV-009：算法注册与预检

- `RoutingAlgorithmRegistry` 注册内置基线和审核过的本地插件，使用精确算法 ID/版本定位实现。
- 设计器提供算法目录、清单注册、JSON 参数编辑、参数 schema 校验和兼容性预检。
- 本地清单注册先运行 SDK 10 案例契约套件；参数或版本不兼容时不启动仿真。
- 报告始终携带算法 ID、版本和参数。

### V02-DEV-010：严格 2×3 配对实验

- `ExperimentPlan v1` 只接受两个身份不同的疏散路由算法和三个不重复种子。
- 计划冻结同一个 `AnalysisCase`、需求、模型、时间轴和种子，复用 V0.1 `run_comparison`，没有平行批跑引擎。
- 六次运行按 `baseline/candidate × 7/42/99` 唯一展开；同一 seed 的两次运行共享配对输入指纹。
- 输入指纹、案例指纹或算法身份漂移会在执行/报告前拒绝。

### V02-DEV-011：算法比较报告

- 延续清场、密度、排队和滞留指标，并增加仿真耗时、路由计算耗时、稳定率、失败率和逐次决策日志。
- 失败运行进入分母；部分失败产生 `partial`，全部失败产生 `failed`。
- 报告不根据单个种子自动输出算法优劣结论。
- HTML/JSON 均披露算法版本/参数、样本数、失败和安全使用限制。

### V02-DEV-012：实验模板薄切片

- 一个可运行 `evacuation-routing-comparison` 模板声明研究问题、锁定变量、可改变量和必需指标。
- “水马位置、出口选择、楼梯/扶梯分流、设施故障”四个模板冻结为保留合同，未伪装成可运行能力。
- 完整性检查机械验证冻结计划、六次运行、配对指纹和算法证据，不判断学生研究结论是否正确。

### V02-DEV-013：工程黄金路径与故障隔离

- 浏览器从模板建立 4 分钟案例，设置 60 秒投放水马、120 秒关闭非关键设施、180 秒启动人员引导，并为每项设置结束动作。
- 选择 `metro.shortest_path@1.0.0` 与 `example.dijkstra@1.0.0`，候选参数 `cost_multiplier=1.5`，完成 6 次配对运行。
- UI 展示耗时、稳定率、失败率和日志数；导出包精确包含：
  - `analysis-case.json`
  - `baseline.analysis-case.json`
  - `candidate.analysis-case.json`
  - `comparison-report.json`
  - `decision-report.html`
  - `experiment-plan.json`
- 导入 `experiment-plan.json` 后恢复时间轴、算法身份、候选参数和案例指纹，并完成复跑。
- 真实慢插件在读取大型站图请求前休眠，宿主使用 0.05 秒请求超时终止子进程；3 次基线成功保留，3 次候选失败均记录 `timeout`，候选失败率为 100%，批次为 `partial`。
- Windows 宿主通过临时输入流传递单行 JSON，避免大型请求写入 stdin pipe 时阻塞；测试后无孤儿慢插件进程。

### 明确后置

- 多因素参数扫描、置信区间/效应量、完整时空诊断、教学作业流、案例库、自动优化、真实数据校准、多人协作、数字孪生和更多 3D 资产。

## 安全与可信度边界

- 仅适合教学、方法研究和受控内部探索；不得用于真实运营、安全认证或消防结论。
- 设施关闭会投影为路由拓扑关闭边；几何水马、隔离栏、封闭区和单向通道约束物理运动，但 V0.2 不把它们重投影为路由关闭边。
- 进程隔离是故障控制，不是不可信代码安全沙箱；插件必须先审查。
- 三个种子只满足 V0.2 工程配对最小值，不构成统计显著性声明。

## 收尾决定

冻结 V0.2 最小功能范围，不再追加功能。工程团队只响应真实用户验收发现的阻塞问题；产品负责人完成剩余两类真实门禁后，再决定是否从 `hold` 转为 `limited pilot`。

# V0.2 R0 后端薄切片验收证据

- 验证日期：2026-07-16
- 范围：V02-DEV-001～003 的后端薄切片
- 薄切片状态：`pass`
- V0.2 发布状态：`hold`

## 已贯通能力

1. `control-plan/v1` 正式定义 `ControlPlan`、`ControlMeasure` 和 `ControlEvent`，包含版本、稳定标识、类型、目标、动作、时刻、参数、来源和语义指纹。
2. 七类管控措施的动作能力矩阵已经冻结；R0 运行时只开放水马和出入口关闭，其他类型会在运行前显式拒绝，不使用空实现伪装完成。
3. 水马可在 tick 边界投放和移除；动态障碍进入真实可行走几何，并触发运动后端刷新。
4. 出入口关闭和恢复被翻译到既有设施中断内核，保持排队、重规划和设施状态的单一事实来源。
5. 计划时刻、应用时刻、应用/拒绝状态、原因和当前活动措施进入帧快照；比较运行摘要会去重保留事件证据。
6. 水马投放区域已有乘客时，事件被拒绝并记录，不会静默改变几何。

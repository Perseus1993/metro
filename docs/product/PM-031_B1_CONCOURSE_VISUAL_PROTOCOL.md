# PM-031 B1 站厅视觉制作协议 v1.0

## 1. 决定与边界

首版 B1 样板采用“西安新建地铁标准站”方向：现代、明亮、克制，以灰色磨石地面、
浅色墙板、分区线路色、铝板/方通吊顶、连续线性照明和紧凑型拍打门闸机为主。
特色站的大型曲面、主题雕塑和高饱和灯光只作为后续可选皮肤，不进入首版基线。

本协议约束 Unity 回放端的非权威视觉层，不改变 Python 仿真几何、路径、排队、设施服务
事件或时间轴。它不是施工图设计或工程合规证明；涉及真实工程时仍需由有资质的设计和
审查单位按标准全文复核。

## 3. 标准依据分级

### A 级：强制性工程规范

- [GB 55033-2022《城市轨道交通工程项目规范》](https://zjj.sm.gov.cn/xxgk/fgwj/jsbz/202209/t20220909_1827382.htm)：作为城市轨道交通工程的总约束；视觉层不得掩盖疏散、无障碍和运营设施。
- [GB 55019-2021《建筑与市政工程无障碍通用规范》](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/202204/t20220412_2674451.html)：样板必须表达连续无障碍路径、宽通道检票口、提示盲道和无障碍电梯信息。宽通道净宽视觉基线不小于 0.90 m；电梯门前保留直径不小于 1.50 m 的轮椅回转空间。
- [GB 55037-2022《建筑防火通用规范》发布信息](https://www.hunan.gov.cn/zqt/zcsd/202301/t20230131_29211615.html)：消防疏散标识和通道优先于装饰；灯箱、售票机、围栏和广告不得侵入疏散主流线。

### B 级：现行推荐性国家标准

- [GB/T 15566.4-2020《公共信息导向系统 设置原则与要求 第4部分：公共交通车站》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=A71816657DA63655674D146DD382A8B2)：入口、分岔、闸机前后和跨层设施处保持信息连续。
- [GB/T 20501.1-2013《公共信息导向系统 导向要素的设计原则与要求 第1部分：总则》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=DAB86FAE54F407AAB637EF36A8544BF4)：约束箭头、文字、图形符号和底板的信息层级。
- [GB/T 10001.1-2023《公共信息图形符号 第1部分：通用符号》](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=9017AD36BDDF54847502415553AD2EFF)：电梯、卫生间、出口等使用标准化图形符号，不自创难辨识图标。
- [GB/T 50034-2024《建筑照明设计标准》](https://zcsys.ncepu.edu.cn/docs/2025-01/d5c197c2837e4892ac7d02faae298500.pdf)：普通地铁站厅地面照度标准值为 100 lx，高档站厅为 200 lx；普通进出站门厅为 150 lx。Unity 不把灯光组件数值直接宣称为真实 lx，只按该相对关系制作和验收曝光。

当 A 级与 B 级或实景参考冲突时，按 A 级执行；当实景照片与项目语义冲突时，以 Python
场景合同为准。

## 5. Unity 实施约束

1. `station_scene.v1` 中的楼层、设施 ID、边界和运行时绑定保持不变。
2. 所有新增构件挂在 `B1HeroSample` 非权威视觉根节点下；关闭样板时不得出现。
3. 材质、装饰、导向和灯光不得参与寻路、碰撞、排队或服务事件计算。
4. 第三方模型进入项目前必须登记来源、许可证、版本、面数、纹理尺寸、LOD 和哈希；仅作为网页参考的图片不得打包进 Player。
5. 300 人回放的性能门槛保持平均 FPS 不低于 30；样板镜头优先用共享材质和模块化几何，避免每个构件生成独立贴图。

## 6. 首版镜头验收

- 1600×900 干净截图中，第一眼能识别“中国城市地铁站厅”，而不是机场、商场或科幻空间。
- 闸机、线路导向牌、售票机、安检区、广告灯箱、盲道和消防/出口标识均可辨认。
- 地面不再出现高对比粗网格；吊顶不再是大面积黑色；画面中至少有浅灰、线路蓝、拉丝钢和玻璃四类材质层次。
- 闸机通道密度接近 R1；至少一条无障碍通道明显更宽，并与盲道连续。
- 导向主信息在截图原尺寸下可读；装饰信息不得与运营信息争夺视觉焦点。
- 同一 Python 回放在启用和关闭样板视觉层时，乘客位置、跨层过程和时间轴采样结果一致。

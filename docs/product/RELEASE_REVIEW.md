# V0.2 发布评审

- 评审日期：2026-07-16
- 候选版本：V0.2 管控措施与疏散算法实验平台
- 目标受众：交通/疏散课程教师、学生和算法研究者
- 当前阶段：R0～R3 通过 / R4 工程通过、真实用户门禁待执行
- 当前决定：**hold**

V0.2 最小工程范围已经完成：七类管控措施、管控时间轴、一个分层疏散路由插件 SDK、严格 `2×3` 配对实验、算法证据报告和一个可运行实验模板均已贯通。V0.1 已有的案例、固定种子批跑、报告包和导入复跑被兼容扩展，没有建立平行实现。

工程验收证据见 `V0.2_R3_R4_ENGINEERING_ACCEPTANCE_EVIDENCE.md`；R0～R2 历史证据继续保留。工程开发可以收尾，但自动化证据不能代替真实教师、学生或算法研究者验收。

## 已验证的候选结果

- 设计器注册内置基线和审核过的本地插件，校验精确版本及 JSON Schema 参数。
- `ExperimentPlan v1` 只接受两个不同算法、三个固定种子和冻结的疏散案例。
- 60 秒投放水马、120 秒关闭设施、180 秒启动人员引导的黄金时间轴完成 6 次配对运行。
- 导出包包含实验计划、冻结案例、基准/候选兼容文件、JSON 报告和 HTML 决策报告；导入后恢复算法版本、参数、时间轴和指纹并可复跑。
- 真实插件在读取大型站图请求前超时会被终止；成功基线保留，失败算法进入分母和决策日志，不产生孤儿进程。

## 安全使用边界

- 当前结果仅适合教学、方法研究和受控内部探索，不得用于真实运营调整、容量承诺、疏散认证或消防结论。
- 进程隔离用于故障控制，不是不可信代码安全沙箱；本地插件必须先审查。
- 几何水马、隔离栏、封闭区和单向通道约束物理运动，但 V0.2 不把它们自动转换为路由拓扑关闭边；设施关闭会转换。
- 未校准状态、失败运行、样本量、算法版本和参数必须随报告传播，不得根据单个种子自动判断算法优劣。

## 正式发布剩余门禁

1. 组织 5 次目标用户黄金任务，至少 4 次成功且模板实验中位时间不超过 30 分钟。
2. 由至少 2 名独立参与者在不修改核心包的情况下接入示例之外的路由算法，接入中位时间不超过 90 分钟。
3. 将真实观察记录追加到验收证据；三轴全部达到 `pass` 后再把决定改为 `limited pilot`。

## 后置项

多因素实验、统计置信区间、完整时空诊断、教学作业流、案例库、自动优化、真实数据校准、协作、数字孪生和更多 3D 展示均不阻塞本轮工程收尾。

# V0.1 目标用户任务测试协议

## 目的

验证目标用户能否不修改代码、无需仓库知识，独立完成一次可复现方案比较，并正确解释结论和使用边界。自动化测试不计入这 5 次任务。

## 参与者

- 地铁客流仿真分析人员；或经产品负责人书面确认、熟悉站点客流分析流程的合格代理用户。
- 不使用本功能开发者作为“独立目标用户”证据。
- 建议招募 3～5 人，共完成至少 5 次独立会话。

## 单次任务

1. 从正式预设建立并导出基准案例。
2. 克隆候选，新增一处阻挡型水马，确认只有该实验变量发生变化。
3. 使用种子 `7, 42, 99`，设置独立的需求窗口和清场窗口，完成 6 次运行。
4. 查看清场、密度、排队、滞留、异常和瓶颈，选择采纳、拒绝或需要更多证据并说明理由。
5. 导出报告包，从包内重新导入案例并复跑。
6. 回答：哪个方案更好、依据是什么、结论不能用于什么决策。

主持人只能解释任务文字，不得代替点击、指出按钮位置、解释指标或修复案例。发生帮助时将 `independent` 记为 `false`。

## 成功标准

单次会话同时满足以下条件才计为成功：

- `independent`：未接受操作或判断帮助；
- `task_completed`：完成创建、比较、决策、导出和复跑；
- `decision_interpretation_correct`：能用报告证据支持方案判断；
- `limitations_understood`：明确结果未校准，不能用于生产运营或安全认证。

版本门禁要求：至少 5 次已完成会话、至少 4 次成功，完成时长中位数不超过 30 分钟。

## 记录方式

每次会话在 `evidence/V0.1_UAT_RESULTS.json` 的 `sessions` 中新增：

```json
{
  "session_id": "UAT-01",
  "participant_role": "客流仿真分析师",
  "status": "completed",
  "duration_minutes": 18.5,
  "independent": true,
  "task_completed": true,
  "decision_interpretation_correct": true,
  "limitations_understood": true,
  "decision": "reject",
  "observations": ["候选密度暴露上升"],
  "friction": []
}
```

执行 `uv run --no-sync python scripts/assess_v01_uat.py docs/product/evidence/V0.1_UAT_RESULTS.json` 生成门禁结论。未完成 5 次真实会话时必须保持 `hold`。

# PM-033:Torch 运动后端 P1 — 可微标定优先计划

- 状态:`proposed`
- 计划日期:2026-08-03
- 前置决策:PM-032 P0 证据(2026-08-02)结论 **GO: constrained P1 R&D**,四门全过
- 计划类型:P1 研发,标定主线优先(go-calibration 路径)
- 预计投入:25~35 人日,建议 8 个自然周内完成
- 决策对象:P1 结束时四选一——`paper-go`(投稿+继续 P2)、`scale-up`(扩展到批量实验基建)、`limited-go`(只保留 GPU 批量能力)、`stop`
- 产品影响:不改变 V0.2 范围;JuPedSim 仍为默认后端;`torch` 仍为可选依赖

## 1. 管理结论

P0 已证明:边界可接入、微场景约束可满足、梯度可用、GPU 批量有收益。P1 不再回答"能不能",只回答一个科研命题:

> 在真实站内运营边界(离散设施/列车不入图)约束下,梯度标定是否比黑箱参数搜索更节省仿真预算,并能在真实行人数据上得到可核验的参数。

一切工作包围绕该命题排序。GPU 加速线降级为维持;Warp、torch.compile、空间哈希、多 GPU 一律不进 P1。

## 2. 战略定位(趋势依据)

- 学术空位:可微 ABM(AgentTorch/GradABM、arXiv:2509.03303)已成范式但集中在疫情/金融;行人侧只有纯数学模型梯度标定和 Deep Social Force 类内核,**没有"真实站型几何 + 离散运营边界下的可微运动标定"工作**。arXiv:2307.01085 指出的梯度噪声/离散不可微问题,恰好被 PM-032 §6.4 的"仅连续参数入图"边界回答,可作为论文设计原则。
- 工业印证:GPUDrive/Madrona、NVIDIA Warp/Newton 验证了固定槽位批量 GPU 仿真路线;MassMotion/Viswalk 校准靠参数扫描、不可微;JuPedSim 路线图偏 V&V 与 Web 化,不做 autograd,继续用作基线与伪观测源,不构成竞争。
- 许可边界延续 PM-032:AgentTorch(AGPL)、VMAS(GPLv3)只读论文不读码。

## 3. 三条工作线

```text
A 标定主线(核心,~15 人日):损失库 → 合成多参数恢复 → JuPedSim 伪观测 → 真实数据
B 支撑工程(blocker,~6 人日):联合接触求解 + 多边形几何张量化
C 维持线(~4 人日):批量 harness、吞吐回归门、证据与决策报告
```

B 先行:接触求解和多边形几何不落地,标定实验的轨迹不可信,主线结论作废。

## 5. 里程碑

| 周 | 内容 | 出口 |
|---|---|---|
| W1~2 | P1-01、02(blocker 清零) | M1~M7 + 多边形薄切片全绿,否则暂停主线评估是否 stop |
| W3~4 | P1-03、04(合成实验) | 预算-误差曲线初版;若梯度法无预算优势,提前触发评审 |
| W5~6 | P1-05、07(伪观测 + 批量) | 模型族差距量化报告 |
| W7~8 | P1-06、08、09(真实数据 + 评审) | 四选一决策 + 论文骨架 |

W3~4 出口是提前止损点:合成数据上梯度法都赢不了黑箱,就不投真实数据的 4~6 人日。

## 6. 决策门(四选一判据)

- `paper-go`:合成实验中梯度标定以 ≤50% 预算达到黑箱同等参数误差;真实数据留出误差不劣于文献已发表基线;blocker 全清。
- `scale-up`:标定优势不显著,但批量实验基建对 rp 线(雨天韧性敏感性分析)有明确需求。
- `limited-go`:仅吞吐达标;冻结标定线,保留 GPU 批量能力待新证据。
- `stop`:接触求解或多边形几何无法在预算内可信落地。

## 7. 风险

| 风险 | 应对 |
|---|---|
| 长仿真链梯度噪声/爆炸 | 截断反传窗口 + 密度代理损失;把该处理本身写成论文方法贡献 |
| 伪观测过拟合(拟合 JuPedSim 而非行人) | P1-05 只报告模型族差距,真实性结论只允许来自 P1-06 |
| 真实轨迹数据缺口(仓库仅 AFC 面板级) | 固定使用 Jülich 公开数据集;不承诺自采;站内真实标定范围限于数据集覆盖的几何类型 |
| 接触求解引入不可微点 | 约束迭代用光滑化投影;参数梯度核验纳入 P1-01 完成条件 |
| 与 V0.2 抢资源 | P1 全程在 experiments/ 与独立分支;不动 `metro_station` 默认路径 |

## 8. P2 展望(不入本计划范围)

标定线达 `paper-go` 后,P2 候选:学习型排斥核(Deep Social Force 思路、自实现)、Warp/torch.compile 内核优化、与 rp 雨天韧性课题合流——用 ADS 客流面板生成需求场景,GPU 批量跑扰动敏感性。本计划不为上述内容预留工作量。

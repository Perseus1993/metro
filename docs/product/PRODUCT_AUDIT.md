# V0.2 产品方向审计

- 审计日期：2026-07-16
- 审计范围：产品文档、正式架构、V0.1 复用链路、管控时间轴、路由 SDK、多算法实验、模板与自动化证据
- 结论置信度：工程范围高；目标用户价值中，仍需真实任务验证

## 管理结论

**V0.2 管控措施与疏散算法实验平台的最小工程范围已经完成，可以停止新增功能并转入真实用户验收。** V0.1 的案例保存、固定种子批跑、比较报告和导入复跑被直接扩展；没有重复建设“子批跑、比较报告、导入复跑”。

正式发布暂不能收尾为 `pass`。自动化浏览器只能证明产品链路可运行，不能证明教师、学生和算法研究者能在时间目标内独立完成任务。发布决定因此保持 `hold`。

## 接口分层审计

四类算法仍保持独立责任：策略接口选择出口/楼梯/扶梯，疏散路由接口返回全局路径，运动模型接口更新局部避碰，实验优化接口跨仿真生成方案。V0.2 只开放 `EvacuationRouting v1`，没有引入万能插件，也没有向第三方暴露 Mesa Agent 或私有运行时对象。

## 三轴成熟度

### 产品价值：3/5，发布门禁 blocked

完整用户链路已由浏览器自动化展示，模板和 SDK 可操作；尚无 5 次真实任务和 2 名独立插件接入，因此不能声称已验证采用价值。

### 仿真可信度：4/5（教学/方法研究）/ 1/5（生产），conditional

配对指纹、管控事件、算法版本/参数、失败率、耗时和决策日志完整；单插件超时不会污染基线。缺少真实数据校准，且几何措施尚未投影为路由闭边，不能用于生产或安全认证。

### 工程就绪度：5/5（V0.2 最小范围），pass

R0～R4 工程范围、全量回归、架构契约、正式站型 smoke、浏览器黄金路径和真实超时隔离均通过。后续不再增加 V0.2 功能，仅处理真实验收发现的问题。

## 剩余风险

1. 把自动化链路成功误写为真实用户 UAT 通过。
2. 把几何阻挡效果误解为插件路由拓扑已经同步闭边。
3. 把本地进程隔离误解为可运行不可信代码的安全沙箱。
4. 根据三个种子中的单次结果下算法优劣结论。
5. 在真实用户门禁前插入自动优化、云协作或美术扩展。

## 立即决策

- 冻结 V0.2 最小功能范围，工程开发收尾。
- 按 `RELEASE_REVIEW.md` 执行 5 次目标用户任务和 2 名独立参与者插件接入。
- 真实门禁通过前保持 `hold`；若失败，只修复观察到的任务阻塞，不扩产品范围。
- 继续传播“未校准、仅限教学/研究”的安全边界。
